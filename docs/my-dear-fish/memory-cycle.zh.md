# 记忆巩固周期

[English](memory-cycle.md) | 中文

一条把所有事记得一样清楚的鱼，其实什么都记不深。鱼脑已经有经历流、情景和召回，但把”活过的时间”变成长期记忆的那一步，只是一个全局的、纯靠模型的作业。这一页定义替代方案：按房间、按睡眠阶段、按间隔复习、也按相关性排序来运转的周期，规模按一台桌面宿主和前两天的真实数据来定。

## 头两天暴露了什么

到 2026-10-23 15:10，线上库里有约 550 条经历、26 个情景、3 条生效事实、0 个章节。291 条群聊经历平均每条 799 字，因为桥把好几条 QQ 消息合批成一条经历。最近 40 行的短期窗口里有 25 条群聊和 15 条她的回复，主人的话几乎没有位置。巩固只跑过三次：一次提炼出 3 条事实，两次判定没有值得留的东西。3 条事实全部来自群聊，而且没有一条带房间范围。

漏斗有三处结构性漏点。窗口是全局的，活跃的群可以把主人的私聊挤出去。提炼提示只问主人和她自己的事实，于是群聊产出噪声，主人自己的对话反而可能落在窗口外。模型什么都没返回、没有模型可用或者调用失败时，水位照样前移，没处理的材料就此隐身。夜里没有整理，周和月没有整合，复习没有排期，召回也不会让任何东西变强或变弱。

## 人类时间线怎么对应

- 工作记忆持续几秒到半分钟。这里对应按房间注入的最近原话，保留 30 分钟、12 行。
- 突触巩固在几分钟到几小时内给经历打标。这里对应每个房间静默 20 分钟或积压满额后的微巩固。
- 睡眠巩固在夜里回放一天。慢波睡眠偏向陈述性事实和要旨，REM 偏向情绪与社会整合。这里对应 03:30 之后两次有上限的模型调用，宿主停机后可以补做。
- 系统巩固在几天到几周里把记忆铺开。这里对应 3、7、21、60 天的复习排期。
- 图式整合把新材料接到已知结构上。这里对应每周对日章节、事实、关系和自我模型的整理。
- 再巩固发生在记忆被重新提取的时候，会把记忆改写一遍。这里对应召回真正用到某个情景或事实时，对召回次数和可信度的更新。
- 遗忘不是删除：原文永远保留，相关性排序（新近、显著、复习次数）决定什么浮上来。

## 先分房间，再谈时间

巩固现在按房间跑，不再用一条全局水位。房间是去掉桥重置后缀的会话 id，所以重置前后的群聊仍然算同一间屋子。主人的私聊和主人在 DSH 里的会话共用主人范围；群聊和好友聊拿到 `social:<会话 id>`。

每个房间在 `consolidation_state` 里各有一条水位。一个房间至少积压两行，并且距最新一行已过 20 分钟，或者积压超过单房间上限时，才有资格进入微巩固。一次微巩固最多处理一个房间，主人优先，所以活跃的群既抢不走主人的位置，也不会在一个 tick 里把模型调用翻倍。

群聊的一行是一批消息，不是一句。社交提示拿到的是压缩后的视图：最显著的行、最新的行，以及字符预算内裁过的正文。提示只问群友、习惯、关系和约定，可以返回一句要旨。它不得返回主人的私生活、秘密、余额或住址。

## 微巩固

微巩固取出一个房间的待处理行，按已存显著性、新鲜度、承诺或身份标记打分，并且无论分数高低都保留最新的几行。细粒度事实只从这份选出来的材料里抽；低显著性的闲聊留给抽取式章节树，那就是要旨通路。只有模型成功回答之后，包括明确回答“没有”，水位才前移。没有模型、传输失败或解析失败时水位不动，同一批材料下次重试，而不是悄悄跳过。

每条事实都带范围，也带来源经历 id。主人范围的事实和房间的社交范围分开。工作台提示只显示当前房间允许看到的一小段事实摘要：在主人会话里是主人事实加社交事实，在其他房间里只有本房间的社交事实。这样语义记忆能影响回复，又不会把整张事实表倒进上下文。

## 夜间睡眠

当地时间 03:30，鱼会对刚结束的那一天跑两个阶段。如果宿主当时关着，下次启动补做错过的那一天，最多补两天，从最早的一天开始。

慢波阶段读这一天的情景、当天学到的事实和最多 8 条到期复习项，返回一段当日要旨、修正或合并后的事实，以及这一天的几条主题。REM 阶段读当天情绪显著和社会性的情景，加上当前的自我模型和人物志，返回一档情绪读数、一条自我模型更新、几条关系笔记，以及最多两个打算。

两个阶段各调用一次模型。结果分别写成巩固经历、生效事实、`self_model`、`people`、`affect_log` 和 `intentions`；当天最显著的情景拿到第一次复习日期。没有新材料的阶段直接跳过，不发空提示。失败的阶段记进 `sleep_runs`，下次排期重试，并且绝不把这一天标记成已完成。

## 间隔复习

情景和事实在第一次巩固三天后进入复习队列。复习顺利就依次推到 7 天、21 天和 60 天。夜间慢波阶段把到期项作为”该回看的东西”带进提示，让模型判断旧材料是否仍然成立、是否和最近几天接得上。阶段结束后，到期项被记为已复习，复习次数增加，下一个日期排好。

召回是第二条复习通路。工作台或 recall 工具真的把某个情景、某条事实送进上下文时，存储层记下这次召回和时间。刚被召回就被对话推翻的材料，走正常的事实覆盖，这就是字面意义上的再巩固。

## 每周与每月整合

每周整理在周一 04:10 跑。它读七天的日章节、生效事实、关系和当前自我模型，写出周要旨、自我模型的修正、关系走向，以及值得留下的打算。每月整理在每月一号 04:20 跑，读这个月的章节和上一版自我模型。两者都只调用一次模型；写的都是巩固经历和结构化行，不写新章节，因为章节树保持抽取式、随时可重建。

## 再巩固与排序

每个情景和每条事实都带召回次数、最后召回时间和下次复习时间。召回会抬高召回计数、记下时间，让这条记忆在下次排序时更有分量。复习次数越多、最近被想起过的记忆，在召回融合里权重更高；但没有任何记忆会被删除或隐藏。

排序字段从不碰经历流和导入记录，只改派生的计数和时间。

## 配置与可见性

新默认值放在 `cycle` 和现有的 `working` 块里。已有 profile 不用重装，插件加载时会补全默认值。

```yaml
working:
  roomRows: 24
  roomChars: 6000
  maxRoomsPerRun: 1
cycle:
  enabled: true
  nightly: { hour: 3, minute: 30, minNewExperiences: 6, catchUpDays: 2 }
  review: { intervals: [3, 7, 21, 60], limit: 8 }
  weekly: { weekday: 1, hour: 4, minute: 10 }
  monthly: { day: 1, hour: 4, minute: 20 }
  maxMicroPerHour: 6
```

没有衰退块。时间只影响排序：召回融合里已有的新近权重就够处理"越近越重要"，间隔复习只追踪哪些被复习过。没有任何记忆被删除或隐藏，原文和事实永远可查。

设置页在原有记忆块旁显示周期状态：每个房间的待处理行数和最近状态，最近一次微巩固、慢波、REM、每周和每月整理，到期复习数，以及复习队列深度。按钮可以补做昨夜、跑一次周整理或月整理、强制一次微巩固。除了这些维护动作，整页仍然只读。

## 回填与验收

升级后的第一次启动，周期会接上还有未处理行的房间，并补做最近一个结束日。对已有的这两天来说，应该产出带群范围的社交事实、一条 2026-10-22 的当日记录、一条有内容的复习队列和一个非空的自我模型，同时 550 条原文一条不动。验收项是：模型可用时，没有房间在三次 tick 后仍然卡着；每条事实都带范围和来源 id；每个结束日只在 `sleep_runs` 里出现一次夜间整理；召回一个刚注入过的情景会抬高它的召回计数；失败的阶段不会推进日期。

## 边界

摘要天生有损。夜间要旨是一段话，不是逐字稿；章节摘要仍然是抽取式的。事实是一小张语义索引，不替代情景。社交事实带房间范围：不会出现在别的房间的摘要里，但主人的摘要可以带上它们。周期每晚最多两次模型调用，每周一次，每月一次，再加有上限的微巩固；模型或零花钱不可用时它继续空转，水位保持原样。
