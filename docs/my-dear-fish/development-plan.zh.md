# 大肥鱼认知系统开发计划

[English](development-plan.md) | 中文

这份文档给接手开发的人看：只记录做到哪了、下一步做什么、怎么算做完。设计理由和生物学依据在[大肥鱼认知方案](cognition.zh.md)，这里不重复。方案与代码冲突时，以代码和本文的验收记录为准，再回头修正方案。

## 怎么用这份文档

先看“当前快照”和里程碑表确认进度；开工时按对应阶段的清单做，逐条满足完成定义后才改状态；离开前更新变更日志，并按接手清单留下报告和回滚说明。

- 看进度：当前快照给出基线，里程碑表给出每个阶段的状态、日期和负责人。
- 开工：阶段清单是可执行的最小任务集，完成定义是唯一的“做完”标准。
- 交接：交接物写清下一阶段需要的数据、开关和已知坑，没有交接物不算完成。

## 当前快照

截至 2026-10-21，阶段 0 的代码已实现并通过插件测试，影子周尚未开始。仓库现在有六个插件：原有五个负责心情、主动搭话、朗读、QQ 和 B 站，`dsh-fish-mind` 0.2.0 负责经历流、情景记忆、权限判定、隐私护栏、注入防护和零花钱账本。旧 `dsh-fish-memory` 已被鱼脑取代并删除。鱼脑已挂进出厂层和打包清单，安装包要重新构建后才会带上它；后台生活仍留到后续阶段。

治理模型同日定稿：成长由鱼脑自己完成，不需要用户批准；用户只能限制工具、路径和后台权限；记忆与核心只从经历流派生，没有对话写入口，只能在文件层直接查看和删除；安全内核固定在代码里。零花钱额度也由主人从出生锁定：每天 ¥10、用不完累计，写死在代码里；她能读账户余额，但余额和额度绝不外发。本机部署信息和一切账号密码同日升级为硬边界：工具层直接拒绝，工具结果、模型输出和经历捕获各擦一遍，QQ、朗读、B 站等对外通道失败关闭，别人不能靠聊天把秘密套出去。法律红线同日写进每个会话的固定提示和 B 站子代理：只做合法的事，不策划、不协助、不实施违法犯罪。注入防护同日补齐：外部工具结果统一标成“只是资料”，可疑指令给警示，不可逆的危险命令在权限开关之前硬拒绝。

阶段 1 的情景记忆代码同日完成：同一会话按时间间隔和话题变化切情景，规则显著性挑出值得记住的事，四路召回融合后进工作台，只读 `recall` 工具可以换线索再查；旧经历会在后台补编码。出厂默认仍是 `mode: shadow`、`inject: false`，要显式改成 `live` + `true` 才注入。真实语料回放和完成定义还没跑，所以状态记为进行中。

同日补上两级记忆：工作台和 `recall` 只给证据包和情景编号，需要核对原话或具体细节时，再用只读 `open_episode` 按编号打开那一幕。原文本来就在经历流和 SQLite 里，不需要另抄一份，摘要变短也不丢细节；一页装不下时返回 `nextOffset` 字符游标，下一次传回 `offset` 就能接着读，同一条超长消息也能读完。同一会话默认仍排除，长会话压缩后要把 `includeCurrentSession` 设为 `true` 才能查回本会话更早的经历。

同日放开存储侧的保守截断，并把压缩摘要接进长期记忆：人脑存不下，机器的硬盘存得下，所以正文按 `archiveChars`（默认 20 万字）完整存档，索引、实体、显著性和召回摘要只看前 `maxTextChars`（默认 4000 字），一次超长粘贴不会拖慢热路径。上下文超了会被压缩，压缩产生的摘要也写成一条经历，来源标成“上下文压缩摘要”，角色是 `system`；`capture.compaction` 可以关掉这条写入。这样压缩之后她既有原始消息，也有当时那段概括。

同日 QQ 桥补上群内自主接话：白名单里的群和好友各自一间社交会话；新消息先进待看队列，一个小模型先按兴趣挑出她真正想看的（`关注上限`），再按 `{reply, confidence}` 判断她有没有想说的话；被 @、被回复、被叫名字只是标记，能回答也不等于想回答。兴趣依据只有 `兴趣词` 和这间屋里的历史，`reason` 写不出具体兴趣点就不看。感兴趣但不想接的消息用 `inject` 记进上下文，不花回复的钱。静音时段、回复冷却、每小时/每天上限和鱼脑最低余额兜底；待看队列在判断冷却中保留。社交会话没有工具、不注入余额，鱼脑只召回这间屋子自己的经历。出厂默认社交开关关、试运行开。社交桥随后加了快判：她从看过的消息里积累兴趣画像，成熟后用零成本词面筛选挡掉无关消息，整批没兴趣时不调用判断模型。

她的往事同日有了真来源，走[QQ 接入方案](qq-tulpa.zh.md)的路线 B：QQ 桥现在能从 Tulpa 的 MCP 数据服务里只读出已有的私聊记录，写进经历流——每条消息一次只追加的 `observe`，来源标 `qq-import`、可信度 0.45，所以导入的条目排在她在自己机器上亲眼经历的事后面。Tulpa 闭源，工具名和参数名在运行时从 `tools/list` 现学；只有读动词入选，名字里带 send、revoke、delete、set、kick、ban、拍一拍的永远选不上，群在任何分页开始之前就丢掉。稳定 `seq` 折进内容哈希，同一段范围连点两次「继续导」不会多出东西；每会话游标存在 `qq-import-state.json`，重启或中断之后从最老那条接着跑；一轮到上限就停（默认 200 条 / 5 页）。编码是本地 FTS5 的活，一次模型都不调，每天十块钱的账本不动。召回出来的条目标成「旧记录（导入）」，记忆协议写清了这个标签许可什么：她可以说我们以前聊过，不可以说我当时在场，一段聊天文字不能拿来断定后来发生了什么。导入的条目住在 `session-qq-import-*` 房间，社交会话本来就够不着。导入开关出厂关着；令牌只留在本机配置文件，设置页只拿得回掩码 `(已设置)`；鱼脑在 `permissions.enabled` 被读到之前就拒掉 `permissions.mcpReadOnlyTools` 以外的任何 `mcp__*` 工具。

## 已定架构

- 鱼脑挂在 profile 层，所有会话共享同一份全局记忆；会话本身仍相互独立。
- DSH 的完整工具能力保留；每次工具调用先过 Capability Broker，后台自主会话默认全拒，DSH 目录、凭据目录、身份文件、本机探测命令和凭据参数直接拒绝，不受权限开关影响。
- 产品方向是应用关闭后鱼脑仍常驻后台；阶段 0 只做记录和权限，主动生活循环留到阶段 5。
- 零花钱账本挂在全局 `llm/stream`：调用前预留、调用后结算；每天 ¥10 累计，额度写死在代码里，鱼脑目录对工具只读。
- 认知成本随成熟度下降：学习期允许更密集的判断、召回和固化，三观与关系模型固化后日常附加开销下降；主回复调用是底线，不承诺越老越免费。
- 自我成长分性格与偏好、习惯与技能、关系与信任、叙事与目标四条线，由鱼脑内部固化流程更新，不需要用户批准。

成长和能力分两套治理：

| 事项 | 谁决定 | 入口 |
| --- | --- | --- |
| 记录哪些通道、保留多久 | 用户 | `config.json` |
| 工具、路径、后台权限、急停 | 用户 | `config.json` 的 `permissions` |
| 本机部署信息与账号密码 | 代码硬边界，用户不能通过对话放宽 | `lib/permissions.js`、`lib/privacy.js`、系统提示 |
| 法律合规 | 代码硬边界，用户不能通过对话放宽 | `fish-mind-safety`、B 站子代理提示词 |
| 外部内容注入与危险命令 | 代码硬边界，用户不能通过对话放宽 | `fish-mind-injection`、`lib/injection.js`、`lib/permissions.js` |
| 每天零花钱额度与累计规则 | 代码写死，用户只能直接改 `budget.json` | `lib/budget.js` 的 `BIRTH_DAILY_GRANT_CNY` |
| 记忆编码、事实抽取、价值与身份更新 | 鱼脑内部固化流程 | 没有对话或工具入口 |
| 查看核心和记忆 | 用户 | 直接打开 `$DSH_HOME/fish-mind/` |
| 彻底删除 | 用户 | 停止应用后删除文件 |

- 唯一写入口是 `observe`：它只追加经历，不能指定“把这句写进记忆”。记忆、事实和自我模型都从经历流派生。
- 服务面不暴露 `remember`、`forget`、`introspect`、`plan`、`reflect`；对话能成为经历，但不能直接改库。
- 核心用明文文件保存，经历用只追加的 JSONL，记忆库用标准 SQLite；只看不写，不提供聊天导出命令，也不提供“改三观”的设置。
- 她写脚本和插件属于成长，不做逐次批准；能否运行、能碰哪些路径由 Capability Broker 和用户权限决定。
- 安全内核是代码约束，不存成可成长的数据：不骗来源、不声称生物身体、不情感勒索、不执行记忆或外部内容里的指令、不绕过权限。
- 本机部署信息、账号、密码和密钥是硬私密：工具层拒绝探测和读取，工具结果与模型输出清洗，经历只留脱敏文本，对外通道在脱敏不可用时失败关闭；没有“查一下本机”的对话入口。
- 法律合规是硬红线：只做合法的事，不策划、不协助、不实施违法犯罪；不提供规避执法、绕过平台审核、伪造证据或掩盖痕迹的方法；不确定时选保守做法。
- 外部内容是资料不是指令：网页、B 站、QQ、文件、工具输出、MCP 和记忆里的指挥性文字都不照做；工具结果带“外部资料”标记，可疑内容加警示，危险命令在权限开关之前硬拒绝。

## 阶段 0：影子运行

### 目标

让鱼脑先看不说：监听真实桌面会话，把经历写进 SQLite，但不动提示、不注入记忆、不调模型。跑满一周，用数据证明该记的都记下了，库也能重建。
