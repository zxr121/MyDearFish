# 大肥鱼设置与搬迁

[English](fish-settings.md) | 中文

设置里的「大肥鱼」页是她的总览，不是第二个配置页：出生设定、性格人设、自定义话术、当前自我提示、记忆、心情、关系、通道、零花钱、自动备份、开发者模式和固定边界都在同一页；出生设定、性格人设、自定义话术、自动备份和开发者模式开关能改，其余只读；朗读卡片关掉后可以在「通道」里重新显示。搬家走一个严格校验的压缩包：设置里下载，设置里导入，格式不对时任何文件都不会被写入；导入随时可用，会覆盖现在这条鱼，覆盖前先整份备份。

## 总览页

页面按「她是谁 → 她记得什么 → 她现在怎样 → 她连到哪里 → 什么不能动」排列。

| 区块 | 内容 | 可改 |
| --- | --- | --- |
| 出生设定 | 名字、物种、外形、怎么称呼主人、主人的性别（女/男/未说）、来历、额外的说话习惯、自由填写的群友关系 | 是 |
| 性格人设 | 部署层注入的整段人设前缀；保存后热应用，下一轮生效 | 是 |
| 自定义话术 | 被问到私事细节时的托词、零花钱用完时回主人的本地回复 | 是 |
| 自我提示 | 当前注入的私设全文，含固定规则 | 否 |
| 记忆 | 经历、情景、事实、今天的条数，最近事实和最近经历 | 否 |
| 心情 | 当前值、标签、最近理由、时间线尾部 | 否 |
| 人物志关系 | QQ 人物志里的名字、别名、熟悉度、见过次数、是否主人；不显示 QQ 号 | 否 |
| 通道 | QQ、主动搭话、语音朗读、B 站各自是否开启；朗读卡片关掉后可在这里重新显示；不显示地址、令牌或登录态 | 仅卡片显隐 |
| 零花钱 | 每日额度、可用余额、今天已花和调用次数；B 站巡检今天已花与四分之一上限 | 否 |
| 自动备份 | 是否定时打包整条鱼、间隔（1–720 小时）、最近一份和下一份、保留 5 份的文件列表；也能立即备份 | 是 |
| 开发者模式 | 是否允许她只读查看本机调试资料；旁边的按钮新开一个创造模式调试会话 | 是 |
| 边界 | 影子/注入模式、权限规则摘要、隐私与注入防护计数 | 否 |

最近经历只做预览：正文会截断，跟在 QQ、群聊、私聊后面的号码打码成 `***`。

总览只在本机设置界面提供。路由挂在 DSH 的 `webServer` 上，按 Host、`Sec-Fetch-Site` 和 Origin 判断请求是否来自本机界面；它不建立身份，也没法替代主人本机文件权限。

## 开发者模式

开发者模式默认关着。关着时，工具读 `$DSH_HOME` 下的任何东西都会被 `private.dsh-home` 直接拒绝。打开后，她可以在主人自己的前台会话里用只读工具和只读 shell 命令（列目录、读文件、搜索这类）查看 DSH 目录里的日志、配置和会话记录，用来排查问题；凭据文件（`.env`、`.credentials.yaml`、`~/.ssh` 等）、身份文件、写入和写入型命令仍然被拒绝，群聊/好友会话、子代理和后台会话也不在此列。每次放行都以 `developer.read` 写进审计。

同一区的「用创造模式开一个调试会话」按钮先把她自己的安装目录注册成工作区（已注册就复用；开发时是源码仓库，安装版是 exe 所在目录），再在那里新开一个空白会话，把预设换成创造模式（`cordis`），鱼的人设和记忆照常带着；创造模式自带的改代码、写文件能力来自宿主预设，不受这个开关限制。排查完把开关关掉，下一次工具调用立刻回到硬拒绝。

开关写 `$DSH_HOME/fish-mind/config.json` 的 `developer.enabled`，只能从设置页改；对话、模型工具和 QQ 都改不了。

## 出生设定

出生设定存在 `$DSH_HOME/fish-mind/identity.json`，字段固定、长度受限、控制字符会被清掉。文件不存在时使用出厂默认：名字「大肥鱼」、物种「鲸鱼娘」、蓝白色长发和鲸鱼兜帽、身边跟着一只小蓝鲸、主人的性别「未说」。保存和重置都走设置页，写入是原子的：先写临时文件，再改名覆盖。

主人的性别只有「女」「男」「未说」三种，提交别的值会被设置页拒绝；旧身份文件里如果只存了指代代词（他/她/TA），会读成对应的「男」「女」「未说」，下次保存后换成 `ownerGender`。它每轮随私设注入，由她据此自己决定提到主人时用「他」还是「她」，并明确压过人设、旧记忆和别人转述里的写法；选「未说」时她不猜，直接称呼主人或用「TA」。出厂人设不再写死性别代词，指代主人时改用「主人」或「对方」。

群友关系是出生设定里由主人自由填写的条目：每条写一个名字和一个关系（比如「时光：妈妈」），最多 12 条，名字和关系各 24 字；没填齐的条目会被丢掉，同一个名字后填的关系覆盖先填的。它每轮随私设注入，在任何会话里都按这些称呼和态度说话。它和 QQ 人物志里自动学到的关系网是两回事：前者是主人指定的，后者是她在聊天里自己认的，设置页仍只读。

`selfPrompt()` 每次从当前身份拼出私设，不再写死名字、物种和主人的性别。改名字会同时改掉提示里的自我称呼、拒绝换身份的答法，以及注入防护里提到的名字和物种；改性别会改掉她提起主人时用的第三人称（「未说」时改成直接称呼或「TA」）。若 `$DSH_HOME/feiyu-mood/config.json` 已经存在，保存出生设定会顺手把 `ownerName` 和 `selfName` 同步过去，避免心情判断还叫旧名字；其他心情设置不动。

固定内核不从设置来，也不读 `identity.json`：隐私、法律、提示注入防护、AI 身份诚实、零花钱额度和 `sealed.fish-mind` 权限规则仍然写在代码里。工具不能写鱼脑目录，所以模型不能靠改 `identity.json` 换掉自己；设置页是宿主路由，不属于模型工具。

## 性格人设

性格人设是部署层的整段人设前缀：DSH `system-prompt` 插件的 `personaPrefix`，在系统提示里排最前的 `deployment:persona-prefix` 段。设置页读的是当前实际生效的那一份：没有自定义时显示 `fish/bundle/cordis.patch.yml` 里的出厂人设，自定义后显示活动 profile 的 `cordis.patch.yml` 里的覆盖。编辑器整段替换，最多 12000 字，换行原样保留，控制字符会被清掉。人设里不能出现 `{{变量}}`：系统提示会把它当成插值变量，未知变量会直接报错，所以保存时就被拒绝。

保存走宿主已有的 `configEditor`：先在内存里校验完整候选配置，再原子写入活动 profile 的 `cordis.patch.yml`，交给 Loader 热应用，不需要重启，下一轮就按新人设说话。文件里的其他配置和注释不被改写。「恢复出厂人设」删掉这条覆盖，而不是把出厂文案抄进去，所以以后升级出厂人设时还能跟着更新。

名字、物种、外形和群友关系不在这里，它们仍在出生设定；隐私、法律、提示注入防护、AI 身份诚实、零花钱额度和 `sealed.fish-mind` 权限规则也不在这里，仍由代码固定。QQ 会话只拼入部署层人设、QQ 场景段和鱼脑记忆；人设仍走同一个 `deployment:persona-prefix` 段，所以换人设不改变 QQ 的段落过滤。

## 自定义话术

设置 →「大肥鱼 → 自定义话术」能改两句本来写死在代码里的本地话：

- **被问到私事细节时**：QQ 群和好友会话的场景提示里教她用这句带过。桥每轮组装提示时现取，已经在聊的房间也不用重启，下一轮就按新句子说。
- **零花钱用完时**：额度拦住主人这一轮时，她不上模型，直接用这句回。群聊仍是安静的 `[不接话]`、内部调用仍返回 `FISH_BUDGET_EXHAUSTED`，都不受这句影响。

两句存在 `fish-mind/config.json` 的 `phrases` 里，每句最多 200 字；换行和连续空白会压成一个空格，首尾空白去掉，留空退回出厂那句。「恢复默认」把两句一起写回出厂值。保存只改 `phrases`，其它配置原样保留；改完当场生效，不用重启或 `reload()`。

## 自动备份

鱼脑会按设定的间隔把整条鱼打包到 `$DSH_HOME/fish-backups/`。装好的桌面版里 `$DSH_HOME` 就是 `<安装目录>\data`，所以备份落在安装目录中；开发环境是仓库下的 `data`。每份包和设置页导出的 zip 一样：出生设定、经历流、长期事实、短期水位、心情和人物志；配置、凭据、零花钱账本和会话记录不在包里。

开关和间隔在设置 →「大肥鱼 → 自动备份」里改，间隔 1–720 小时，保存后当场生效，不用重启。任务每分钟检查一次，从最近一份备份的时间算起，过了间隔才写新的一份，所以重启不会因为启动次数多而重复备份。关掉自动备份后仍可点「立即备份」手动写一份。

最多保留 5 份，超过时从最旧的删起。只清理大肥鱼自己写出的 `mydearfish-YYYY-MM-DD-HHMMSS.zip`（同一秒的第二份带 `-2` 后缀）；`fish-backups` 里你自己放的其它文件不会被删。备份先写临时文件再改名，写到一半中断不会留下半个 zip；如果 `fish-backups` 被同名普通文件占着，这一轮会报错停下，不会改写它。有导入包等重启或检索库正在重建时，自动备份跳过这一轮，等下次检查再试。

备份只是副本，不能代替搬家：把鱼交给别人仍用「导出整条鱼」。卸载桌面版时会询问是否删除 `<安装目录>\data` 里的记忆、聊天记录和设置；选「否」或静默卸载都会保留，以后装回同一目录会接着用。

## 搬什么、不搬什么

压缩包只装「她这个人」的成长数据，不装这台机器和这个账号。

| 条目 | 内容 |
| --- | --- |
| `manifest.json` | 格式名、版本、导出时间、名字、每个文件的字节数和 SHA-256 |
| `identity.json` | 出生设定 |
| `memory/experience.jsonl` | 只追加的经历流，记忆的重建源 |
| `memory/facts.json` | 当前生效的长期事实快照 |
| `memory/working.json` | 短期提炼水位；没有水位时省略 |
| `mood.json` | 心情、七个情绪维度、最近理由和时间线；没有心情状态时省略 |
| `people.json` | QQ 人物志：跨群和私聊认人、关系与共同话题；没有人物时省略 |

不导出：`config.json` 的整体、`budget.json`、`budget-ledger.jsonl`、`audit.jsonl`、`diag.log`、`mind.sqlite*`、`state.json`、任何凭据、账号与群号、目标会话、本机路径，以及 DSH 会话记录。本机设置只按白名单收进 `manifest.configs`（鱼脑、倾向、自定义人设、心情、QQ、主动搭话、朗读、B 站），新加的配置字段默认不进包。零花钱按新主人自己的账户重新出生；通道登录态留在原机器。

导出时现读经历流、事实和心情，不复制 SQLite。压缩包用 `node:zlib` 的 deflate 写，不依赖运行时第三方包；`manifest.json` 给每个条目算 SHA-256。下载文件名固定为 `mydearfish-YYYY-MM-DD.zip`，避免中文文件名在响应头里编码不一致。

## 严格导入

导入先完整读进内存并校验，任何一条不通过就只返回错误，不碰现有文件。

- 必须是 ZIP；拒绝加密、数据描述符、ZIP64、多磁盘、非 deflate/store 压缩、目录条目和绝对路径或 `..` 路径。
- 条目数量和单条、总解压体积都有上限；中央目录、局部头、压缩前后大小和 CRC32 必须一致。
- 只接受 `manifest.json` 和上表里的六个数据条目，多一个文件、少一个文件、清单里没列或校验和不符都拒绝。
- `manifest.json` 只认 `mydearfish.fish` 格式和版本 1；`identity.json`、`memory/experience.jsonl`、`memory/facts.json` 必须存在。
- 经历逐行必须是 JSON 对象，带时间、64 位十六进制哈希和非空 `kind`；事实、心情、人物志按各自结构检查，坏结构直接拒绝。
- 随时可以导入并覆盖：现在这条鱼有多少经历、心情和人物志都照收，不再要求空鱼。导入会把出生设定、经历流、长期事实、心情、人物志和短期提炼水位整个换成包里的内容；包里没有心情、人物志或水位时，本机对应的旧数据会清掉，导入完就是包里那条鱼，不和旧鱼混着过。

通过校验的压缩包先落到 `$DSH_HOME/fish-mind/.import-pending/`，设置页显示「已暂存，重启后生效」。下一次启动时，鱼脑在打开 SQLite 之前重新校验暂存文件，把现在这条鱼整份备份到 `$DSH_HOME/fish-mind/import-backup-<时间>/`，写入经历、身份、心情和人物志，清掉包里没带的旧心情、人物志和水位，删掉 `mind.sqlite*`，再按导出包里的水位恢复短期提炼进度，从 JSONL 重建索引。事实快照在库打开后逐条写回。应用完成后写 `import-report.json`，设置页在下次打开时显示导入结果和备份目录名，需要回滚就把备份拷回去。

暂存之后新聊出的经历会在重启时一起被覆盖，所以包暂存后先别聊重要的事；导入包在等重启时，设置页不提供导出，避免把「还没生效的鱼」和「现在的鱼」混成一个包。

## 失败与恢复

压缩包格式不对、校验和不符或条目越界时，导入返回 4xx 和一句可读原因，现有 `identity.json`、经历流、心情和人物志都不改。暂存包在启动时重新校验失败时，这次导入被丢弃并写拒绝报告，鱼脑照常打开当前数据。应用中途失败则保留暂存目录，下次启动继续尝试；`import-report.json` 和 `diag.log` 记录过程。导入前的现有文件和设置备份在 `$DSH_HOME/fish-mind/import-backup-<时间>/`，需要手工回滚时直接拿回去。

这套搬迁不改变安全边界：导出由主人本机点击触发，压缩包里可能有聊天原文和关系，设置页会明确提示只交给自己信任的人；导入只写档案、学习数据和按白名单搬来的偏好，对外通道在导入时强制关掉，权限、额度和代码不动。
