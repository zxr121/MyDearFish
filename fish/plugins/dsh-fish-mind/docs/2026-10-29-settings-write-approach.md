# 倾向落设置 + 开发者模式改设置（2026-10-29）

## 现状与问题

- 设置页「性格倾向」的预览写着「主动话量 6/时·40/日 → 9/时·60/日」（现有旋钮），但保存后只写 `tendency.json`。
  QQ 桥在**读取时**乘/加 `proactiveScale`、`thresholdDelta`、`attentionScale`，`qq-bridge-config.json` 里的
  主动每时、主动每日、判断阈值、关注上限仍是基础值。主人在「通到QQ」页看到的设置和她的实际行为对不上。
- 开发者模式只给主人自己的前台会话开只读通道（日志、配置、会话）。她能读设置，但不能替主人改设置；
  主人在对话里说「把主动话量调低」时，她只能让主人自己去点设置页。

## 采用的做法

### 1. 倾向保存时真的写设置

- 保存倾向时，`talk` 维度的四个值直接写进 `$DSH_HOME/qq-bridge-config.json` 的 `社交`：
  主动每时、主动每日、判断阈值、关注上限。写入保留文件里其它字段和未知字段。
- `tendency.json` 增加 `applied` 记录：写入前的 `base` 和写入的 `written`。
  - 同一句话再保存一次不会叠加：当前值仍等于 `written` 时从 `base` 重新算。
  - 改口（安静 ↔ 活泼）先从 `base` 还原再按新方向算，不会在旧结果上继续乘。
  - 清空倾向时，如果当前值仍是它写的，还原 `base`；主人手动改过就尊重手动值。
  - 主人手动改过 QQ 设置（当前值 ≠ `written`）后，启动/重载只丢掉 `applied` 记录，不再覆盖；
    只有主人再次点「保存倾向」才以当前值作为新基础重新落地。
- 升级迁移：旧版 `tendency.json` 没有 `applied`，启动时按当前 QQ 值算一次并写入，避免升级后行为回退。
- QQ 桥去掉读取时的三个数值缩放，只保留 `talk.mode`（提示和「超过阈值才接」的额外把关）、
  `length`、`stickerSend`、`stickerSave`。写入的是真实设置，桥设置页看到的就是运行时用的值。
- 预览的落点标签从「现有旋钮」改成「写入设置」，并区分：保存后写入 / 已写入 / QQ 桥没配置 / 写入失败。

### 2. 开发者模式下她可以帮主人改设置

- 新增工具 `fish_config`，在主人自己的前台会话注册（社交会话和子代理不注册）：
  - 不带 `patch` = 读全部设置项（键、页面、含义、当前值）。
  - 带 `patch = { "qq.proactivePerDay": 60 }` = 改；每次返回 `before`/`after`。
- 写操作由 Capability Broker 把关：必须 `developer.enabled === true`、主人前台会话；否则拒绝并提示去
  「大肥鱼 → 开发者模式」打开。读取不需要开发者模式。写入记审计（`fish.settings.write`）。
- 设置项只覆盖行为旋钮：
  - 通到QQ：主动每时、主动每日、关注上限、判断阈值、学表情、模式、称呼、兴趣词、不聊话题、冷却秒。
  - 主动搭话：总开关、间隔分钟、峰时命中线、谷时命中线、安静起止、触发文案。
  - 大肥鱼：性格倾向原文（走和设置页相同的保存/落地路径）。
- 明确不开放：试运行、总开关、群/好友/关掉/只听名单、静音时段、最低余额、学说话、记人、预算、记忆、
  搬迁、自动备份、权限、凭据、代码、DSH 目录写入。

### 3. 其它

- 设置页「开发者模式」文案和「她能改的设置」只读清单；「性格倾向」说明改成「保存后会直接写进对应设置页」。
- 不做的部分：不让倾向顺手改「主动搭话」或「鱼的心情」；这些页面的数值各有自己的口径，
  由主人在对话里让 `fish_config` 改（主动搭话已包含）或自己点设置页。

## 代码位置

- `lib/config-files.js`：配置 JSON 原子读写、QQ 社交段和主动搭话配置的读取/合并。
- `lib/settings-catalog.js`：设置项清单、校验、批量应用、`fish_config` 的读写值。
- `lib/tendency.js`：`applied` 记录、`planTalkTuning`/`applyTendencyTuning`、预览文案。
- `lib/index.js`：路由、启动迁移、`fish_config` 注册、overview 设置清单。
- `lib/permissions.js`：`fish_config` 写操作的开发者模式门槛和审计。
- `fish/plugins/dsh-qq-bridge/lib/host.js`：删除倾向的读取时数值缩放。

## 验证

- `node --test fish/plugins/dsh-fish-mind/tests/*.test.mjs`
- `node fish/plugins/dsh-qq-bridge/tests/社交半边.mjs` 与 `宿主半边.mjs`（按各自 README 的方式）
- 手工：保存「多主动一点」→ 看 `qq-bridge-config.json` 变成 9/60/0.34/15，通到QQ 页显示新值；
  再保存「安静一点」→ 回到 4/24/0.46/9；清空 → 回到保存前的基值。
- 手工：开发者模式关着时让她改设置 → 拒绝并提示；打开后改 → 成功、设置页看到新值。
