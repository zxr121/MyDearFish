# 追问自发表情与深想（2026-11-06）

## 事故

群 795789868，14:10–14:16：判断模型盲挑 `#124 表情` 发出去；主人问“这是什么”，她答“就是张脸圆圆的呆图”；被指出“图和你备注的不一样”“再仔细思考下”后，她先说“我看仔细了，说不出个准的”，再说“我这边看它就是一张表情图，差在哪我是真没看出来”。

思绪日志里她其实写了“我看不到图的内容，只能从之前的上下文推断”“这轮没有新的图给我”。也就是说：**她不是没想，是手里真的没有那张图**，却仍然拿印象顶了上去。

## 根因

1. 她自己发出去的表情，在会话里只留一行 `[发了一张表情包：#124 表情]`；原图不落盘，也没有回看入口。
2. `#124` 是自动收藏的，标签只有“表情”；回复提示把它和别的未命名表情合并成一串编号，判断模型却能盲挑它发出去。
3. “备注”在提示里只被当成改备注指令，没写清它就是收藏里的名字；她把聊天里顺口说的描述当成了备注。
4. 深想只在每轮判断之后统一发生，没有“对方在追问/让我再检查”这一层；短应路径也没有为这种回合让路。

## 处理

- **能回看**：收藏条目保存来源图址；别人回复她那条表情消息，或冲她追问“这张 / 图 / 备注 / 收藏”时，按需下载原图、存进附件库，作为“你自己刚发的表情”附进这一轮。取不到图时明确写“你看不到”，并禁止猜画面。
- **不盲发**：`表情 / 未命名 / 图片` 这类占位标签统一显示为“未命名”；判断模型的盲挑清单只保留起过名或标过场合的表情，只有被点到编号时才发未命名的。
- **说得清**：回复提示新增“收藏备注就是收藏里的名字”“看不到就承认、别推回去”的规则；原来“认错图就照指的那张重答”改成“这轮给了图就照图重答，没给图就照实说看不到”。
- **想得深**：新增 `社交.深想`（默认开）。追问样式命中，或十五分钟内同一场话她开口两次以上且基本是同一个人在接，这一轮：
  - 跳过判断模型的短应；
  - 推理档临时升一档（low → high、high → max；off 不硬开，非 DeepSeek 路由不动）；
  - 提示里加【认真核对】，要求先对原话、图注/编号、刚发的图和记忆，再回答。

## 为什么不是“所有回合都调到 max”

线上这间屋本来就是 `deepseek-flash + max`，思绪日志也有完整推理；这次失败不是档位不够，而是证据没递到手里。深想的价值在于**改行为**（不短应、先核对、看不到就承认），档位提升只服务于那些把「回复推理」调低过的部署。

## 验证

- `fish/plugins/dsh-qq-bridge/tests/社交半边.mjs`：新增自发表情原图回看、未命名表情不盲发、深想跳过短应 / 抬档 / 回合结束恢复、中高档映射用例；原有用例全部通过。
- 回复提示快照断言覆盖新增的【认真核对】【收藏备注】【你自己刚发的表情】文案。
