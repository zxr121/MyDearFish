## 逐条核查

### 1. 群聊回复没营养

已经有的四道闸门：

- 空应声：`只是空应声`（host.js 2501 附近）认出“哈哈 / 好家伙 / 确实 / 这什么 / 救命”这类放到哪句下面都成立的话；判断模型的 `short` 写这种会被压掉，正常回复只憋出这种且没被叫到时整轮不发。
- 万能评价：`只是空泛评价` + `近用评价词`（host.js 2452、2515 附近）压掉“好可爱 / 绝了 / 太萌了”，同一个词半小时内不重复。
- 看图写话：群里的随手图不再直接喂给回复模型，只有表情、收藏、转发、视频或明确问图时才带图（`回复图们` 过滤，host.js 10861 附近）；看图提示写明别念发色、配色、耳朵、眼睛。
- 复读：只在两三个人接龙或本群口癖时提供 `[复读]`，同一句 30 分钟内不重复。

还差的一截：`吐槽态` 只有 30 分钟（host.js 4299-4300），过了半小时她又会开始只发表情、复读。报告里 11-04 被集中吐槽、11-05 还在发生，说明 30 分钟不够。这一轮改成：

- 记下被嫌的具体行为：表情、复读、看图、空话、瞎引用。
- 前 30 分钟维持现在的强收敛提示；同一间屋 24 小时内，对应行为直接拦：不纯发表情、不复读、不给看图评价、不空应声。
- 状态写进 `qq-bridge-social-state.json`，重启不复位。

### 2. 引用与识图混为一谈

已经有的：

- `摘引用标记` / `找引用消息`（host.js 3940-4005 附近）只挂对得上的那句；对不上就不挂，不退回自动引用去挂错人。
- 短应用判断模型给的 `shortFor`，不再拿 `批[0]`（0.2.136）。
- 别人追问她刚发的表情时，把原图重新递进去，标“你自己刚发的”和收藏编号（0.2.138）；取不到图就明说看不到。

还差的：提示里没有一句话把“引用错”和“识图错”分开。这一轮在群聊和私聊提示各加一条：

- 引用没对上：这条不挂引用，只发正文；被指出来就认“引错了对象”，不许说“我看不清图”。
- 图没看清：说没看清或问是哪张，不许拿“引用错了”顶。

### 3. 群聊分不清在跟谁说话

已经有的：收件人继承同一人 120 秒内的上一句；`[对你]` / `[对别人说]` / `[旁听]` 标记；判断提示里写明没 @、没叫名字、没回复她就不算对她说话；[问别人] 的消息不插。

还差的，也是 11-08 洛樱定位到的那个：`[不接话]` 只在整串精确匹配时才当成不接（host.js 12426）。模型多打一个换行、一个句号，或者写成“算了，[不接话]”，这串标记就会原样发进群里。这一轮改成：

- `[不接话]` 在任意位置剥掉；剥完只剩标点、空白、省略号、问号，也按不接处理，一个字都不发。
- `[不起话]` 同样按任意位置处理。
- 补冒烟用例：带换行、带句号、只回一个“？”、标记夹在正文里。

### 4. 记忆边界

已经有的：

- 群聊里受信的人说“更正备注”，她真能改（0.2.130）。
- 明确说“记住”的消息进鱼脑并回读核对，没有回执就改成“我没记住”（0.2.133）。
- 明确承诺的记忆跨屋可答；标“保密”的只在原房间说；私聊里主动说的近况存成“密”事实，群里别人套不出来（0.2.135）。

没改的：跨屋普通事实仍然只在本屋召回，别处的标来源、私下说的不当众点名。这是有意的安全边界，不是漏做；“只有它自己的记忆”指的是她不会把别人私聊的内容带进群，这一条要保持。

### 5. 时间感与心情记录中断

时间：`timePrompt`（fish-mind index.js 1474 附近）每一轮都给“现在是 …”，并算出上次说话隔了多久、跨没跨夜；记忆里的时间也统一换成今天 / 昨天 / N 天前（time.js）。这一条已闭环。

心情：这是一条真 bug。心情插件在 `agent/turn-stopping` 里直接 `if (!cfg.autoJudge || 社交会话(sid)) return`（dsh-feiyu-mood/lib/index.js 574 附近），把所有 `qq-social-*` 房间全跳过。主人从 11-06 晚上起主要在 QQ 群里说话，那间屋永远不判心情；只有 `speak-up` 在主会话里开口时才偶尔记一条。现场 `data/feiyu-mood/diag.log` 能对上：11-06 之后所有“心情更新”都标着“（自己搭话）”，没有一条来自正常聊天。

这一轮改成：

- `qq-private-*`（主人私聊）照常判。
- `qq-social-*` 只有这一轮的入站消息 `source.owner === true` 才判；群友之间的话不判，省一次调用，也不把群里的私事写进心情理由。
- 每次跳过写一行 diag，方便下次定位。

### 6. 表情包

已经有的：商城表情按官方名和系列名收（0.2.140）；备注按画面起名，不拿场合凑（0.2.139）；旧收藏能按原图重看；只存可爱、按群语感挑表情。

还差的：

- 收藏条目里只有一串 `source: "群 123·某人"`，她回答“哪来的 / 哪偷的”时用不上。
- 挑表情时没有“这屋的优先”，但按群硬隔离又被洛樱否掉了。

这一轮：收藏时记来源房 `房`；被问来源时同屋直说“在这个群见到的”，别屋只说“在别处见到的，觉得好玩就存了”，不报群号和人名；挑表情时本屋的排前面，别屋的仍可用。

### 7~10. 好感度、频率、成本、人设

- 好感度：0.7.35 已从五维扩到十维（理解 / 信任 / 尊重 / 需要 / 自在 / 熟悉 / 亲近 / 互惠 / 承诺 / 修复），聊天只说阶段。`隔阂值` 只由负面账目推导，共情本身不会加隔阂；报告里那次更像是负面场景和维度太少叠在一起，这一轮跑回归用例确认。
- 频率：少说、主动额度、动态冷却、安静倾向都在；`不是不理你，只是似了而已` 是进程被杀，不是逻辑问题。
- 成本：`budget.js` 的出厂价目表按 DeepSeek 官方峰谷价挂模型名，工作日 09–12、14–18 高峰，其余和周末谷时；未配价的模型才落 DEFAULT_PRICE 并标 `pricingMiss`。
- 人设：引用和转发里的称呼不再算叫她（0.2.132）；恢复出厂会删掉覆盖，不把出厂文案抄成自定义。
