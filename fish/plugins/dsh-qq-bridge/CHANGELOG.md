# 改动记录

> **版本号规矩**：每改一次 **+0.0.1**；末位满 10 **进位**（`0.1.9` → `0.2.0`）。
> 版本号只写一处真源：`package.json`；提交信息也以版本号开头。

## 0.2.79

**群聊不再被其他 AI 拖着烧钱：能按群少掺和，也能按人少理 / 不理**

- 🎛️ 「每一间的开关」多一档「少掺和（只接叫我的）」：没叫她的群友消息不进待看，不下载图片、不判断、不开回合；主人随口说的仍照常；
- 🙅 「她跟谁说话」按群列出见过的人，每个人可设正常 / 少理 / 不理：少理 = 没叫她不看、被叫只短答一句；不理 = 连 @、回复、戳一戳都不接；主人永远不受影响；
- 💸 这些规则在进待看前生效，群里几个 AI 互相刷屏时不再按条烧判断和回复的钱；
- ✅ 补了冒烟断言：不理的 @ 不进判断、少理只在被叫时接且带 [冷处理]、少掺和保留主人和叫她的话；/save 只留开着的群和有效号；设置页能渲染新开关。

## 0.2.78

**图里细节被点名问就照答：不把“别念图”做成回避**

- 🔍 对方明确问图里的颜色、人数、写的什么字时照问照答，不绕开；随手发图 / 表情时仍然只接意思，不逐项念画面；
- ✅ 社交场景提示和主人私聊提示的断言补上这一条。

## 0.2.77

**被戳就回一句，看图不念图：不再自导自演门铃小剧场**

- 🚪 戳一戳只按“有人戳了你”短回一句（在呢 / 干嘛 / 戳我做什么）；提示里明确禁止把它改写成门铃、敲门、有人上门这类场景；
- 🖼️ 别人发图 / 表情时接图的意思，不再逐项念发色、配色、耳朵、眼睛，也不替静图编“喊破嗓子 / 急出来的”这类动作；拿不准就短问，或只说看懂的那点；
- 🎭 群里不自导自演：不把群里的人写进她看不见的场景，没有前文支撑的“又 / 这回”不讲；自己起的比喻没被接住就收，不隔几个小时再翻出来当开场；
- 📝 场景提示和主人私聊提示、回复轮都补了对应断言。

## 0.2.76

**暗色主题下「每一间的开关」下拉不再白底白字**

- 🌗 原生下拉的弹出层自己画白底、只继承字色，暗色主题里「正常 / 只听不说 / 关掉」几乎看不见；选项现在自带主题底色和字色，浅色主题照旧；
- 🎛️ 同一页的模型、目标会话、模式下拉一并修好，换主题也跟着变；
- ✅ 补了断言：每个选项都得带主题底色和字色。

## 0.2.75

**群里聊游戏不接话：没带游戏名的跟话、游戏截图和接梗也拦住**

- 🎮 游戏词表补上“黑猴、爬塔、开黑之后的上线、副本、打野、段位、吃鸡、赛季”这类常见说法；只发截图、只接着聊“水口 / 大炉子 / 基地”这种没关键词的句子也不进判断；
- 🧵 刚聊到的游戏话题会记住在场的几个人，之后四分钟内他们接着说的话按同一话题略过；别人另起一句仍照常交判断；
- 🛡️ 判断提示和回话提示都收紧：游戏和不聊话题“接得上也不接”，不装懂、不接梗、不复读；只有被直接叫到才照实说一句“我不玩/不太懂”；
- ✅ 补了游戏词表、无关键词跟话、话题余温过期后恢复接话的测试。

## 0.2.74

**私事托词改成设置里能自己写：群里被追问细节时照你写的说**

- ✍️ 社交场景提示里的私事托词不再写死“这个我不方便细说”，改从鱼脑设置页「大肥鱼 → 自定义话术」读；没装鱼脑或没设置时仍用出厂那句；
- 🔄 场景提示改成每轮现取，已经在聊的群和好友房间不用重启，设置改完下一轮就生效；
- ✅ 补了自定义托词的断言，场景提示正文按真实组装方式取值。

## 0.2.73

**@ 只交 QQ 号，名字让 QQ 自己显示：不再自己拼“@ + 名字”**

- 📮 at 段里只放对方的 QQ 号，不再塞入我们自己写的名字；显示出来的名字由 QQ 按群名片取，跟自己按 @ 时一样；
- ✍️ 句子中间、甚至 `@名字` 后面紧接正文（“@七味糖在吗”）也能认出来；句首认不出的 `@` 直接去掉，不再把假的 @ 当文字发出去；
- 🚫 邮箱、英文句柄里的 `@` 不当成叫人；同名、认不出的人仍然只留名字；
- 🧹 @ 后面不再多发一个空格（QQ 自己已经带了一个）；
- ✅ 补了句中 / 紧接正文 / 假 @ / 邮箱的断言，集成用例改成只校验 at 段里的 QQ 号。

## 0.2.72

- 🏷️ 设置页「每一间的开关」标成 `群 摸鱼小分队（719305529）` / `好友 备注（QQ号）`：群名优先群备注、好友备注优先昵称，读不到名字就照旧只显示号；
- 📖 名字只读本机后端的群名单、好友名单（`get_group_list` / `get_friend_list`），没接上 QQ 时不打扰后端；名单 10 分钟内复用，有房间还缺名字时每 15 秒重试；
- 🧠 后端名单还没读到（或不给）时，好友用人物志里认过的名字兜底；社交状态行也一并显示名字；
- ✅ 补了网页半边与宿主 /state 的断言：名字翻号、缺名回退。

## 0.2.71

**只听不说的那一间：照常认人、学说话，但一句都不发**

- 👂 每一间群 / 好友从两选一变三选一：正常 / 只听不说 / 关掉；只听不说的那一间照常轮询、照常判断，认人、记事实、学说话方式、进记忆一样不落，只是永远不开口；
- 🙅 被主人点名、被 @、被戳一戳也不回；静音时段也照常学（反正不发），其余闸门（试运行、零花钱）照旧；
- 🛡️ 已经在想的那一轮途中改成只听不说，也会在发出去之前被拦住；
- ✅ 补了只听不说的判断路径、主人叫不接、静音照学、在途回合被拦、/save 三态归一化的测试。

## 0.2.70

**群里叫人用 QQ 真正的 @：不再把名字写成纯文本前缀**

- 🏷️ 群里回复开头直接写的群友名字（“美好时光海苔 米饭就米饭…”），前面带不带 `@` 都算，发出去会变成 OneBot 的 at 段，QQ 里显示成真正的蓝色 @，能点开名字；
- ✍️ 提示词教她新写法 `[@名字]`：要专门叫谁就写这个标记，桥按这间屋最近说过话的人把名字对到 QQ 号，一句话里叫几个都认；
- 🔎 名字不用一字不差：只写了名片里够长的一截（“美好时光海苔”对上“我要吃美好时光海苔”）也认得出；同名、认不准的人不猜，只留名字，不发假 @；
- 🔒 只 @ 这一小时在这间屋里说过话的人；好友私聊不 @，标记会退成名字，不会把方括号原样发出去；
- ✅ 补了开头名字、`[@名字]` 标记、短名字、同名不猜、认不出留名字、群里真发 at 段的测试。

## 0.2.69

**私聊说存就真存、说发就发那张：不再嘴上说“存好了”，也不拿像的顶替**

- 📥 主人私聊 / 主人桥说“这个存下来 / 收藏一下”时，这一批里他发的表情会当场写进 QQ 收藏，不用等她回话再动手；存失败会在图注里记“没存成”，不会假装存好；
- 🔁 要“把这张发回来”时她写 `[发表情:图N]`（这一批的第 N 张）：没收过的先存再发，发出去的就是这一张，不用猜新编号、也不会拿一张像的顶替；
- 🏷️ `[存表情:图N:短名字]` 现在私聊也生效：自动收藏的“主人让存”会被她起的短名字覆盖，并同步回 QQ 收藏备注；
- 🧠 私聊提示补上收藏号和写法：标着“你收藏的 #N”的才是存过的，没写成标记就别在话里说“存好了 / 发出去了”；
- 🤫 收藏是她自己的小动作：群里存了不汇报、不 @ 主人邀功，被问起再照实认，清单里没有的不会顺口说存过；
- ✅ 补了私聊说存就存、按编号发回、按图号先存再发、同一张重发认编号、短名字改名同步备注的测试。

## 0.2.68

**每一间群 / 好友都能单独开关：不用增删配置也能让她闭嘴**

- 🔀 社交配置里新增「每一间的开关」：配好的每个群 / 好友各有一个勾选框，勾掉的那一间她不看、不接话，戳一戳也不理；
- 🧾 关掉的只是这一间的开关：群 / 好友清单、聊天记录、人物志和会话都留着，重新勾上就接着用；
- 🛑 关掉的那一刻，已经在想的那一轮也会被拦住，不会关了还发出去；
- ✅ 补了单独关群、没关的好友照常、在途回合被拦住、重新打开恢复、非法房间键被清掉的测试。

## 0.2.67

**回头问旧图不再认错：旧图重新附上，不拿这轮新图硬套**

- 🖼️ 这一轮的话在说“图 / 照片 / 像不像 / 这是你吗”时，最近聊过的旧图会重新附上（先挑这轮说话人之外的人发过的，最多 2 张）：之前上下文里只剩 `[图片]`，她看不见，就会拿这轮新发的图硬套；
- 🏷️ 旧图标成 `[旧图 N]`，图注写清“之前发过”和是谁发的，跟这轮新图的 `[图 N]` 分开；带旧图的上下文行不会被字数预算挤掉；
- 💰 没说图就不重复附旧图，省图钱；
- 💬 有人问“这张像不像你 / 这是不是你”时先直接答像或不像，再最多补一句，不逐项念图里的颜色和衣服；认错图就一句“我看岔了”，照对方指的那张重答，拿不准是哪张就问；
- 🚫 别人随手发的图不算在问她，别把两张图都说成“都问我”；
- ✅ 补了回头问图重新附旧图、图注标发送者、无关新图不重复附旧图，以及认图回话规则的测试。

## 0.2.66

**表情不再认错：同一张按内容对上收藏编号，两张不同的不会被说成一张**

- 🏷️ 收到的图如果和 QQ 收藏里的某一张字节相同（md5 一致），消息行、图注和判断提示都会标出「你收藏的 #N 名字」；判断、回复和短期上下文都带着这个编号，过几轮再提“刚那张”也分得清；
- 🔢 提示里直接写「图 N 就是你收藏的 #N」并给出可发编号：要发就发那个编号，别换成别的编号，也别把别的表情说成这一张；没标“你收藏的”就是没收藏，不再说成存过；
- 🧠 她自己发出去的表情也按「#N 名字」记进缓冲和思路（`[发了一张表情包：#N 名字]`）：谁发的哪一张，下一轮仍然分得清；
- ✅ 补了同一张表情重发、按编号发送、下一轮上下文仍保留编号的测试。

## 0.2.65

**图片她真的看得见：判断模型也拿到图，纯文本模型不再悄悄“装瞎”**

- 👁️ 判断模型能看图时，这一批最多 2 张新图会随判断请求一起递过去，消息行尾标 `[图 N]`、下面带图注；她按图里的内容决定接不接，不再只凭“有张图”猜；
- 🚫 判断模型是纯文本时不硬塞图片，避免整轮判断被模型拒掉；这批消息仍按文字正常判断；
- 🏷️ `/models` 和设置页的模型下拉现在标出「仅文本」，选中纯文本模型时直接提示“她看不到图里的内容”；社交状态里也写明回复 / 判断模型能不能看图；
- 🔔 回复模型是纯文本、又收到图片时，日志提醒一次并给出可换的看图模型，不再毫无提示地让图片变成占位文字；
- ✅ 补了判断带图、纯文本判断不塞图、纯文本回复提醒、`/models` 与 `/state` 看图标记的测试。

## 0.2.64

**QQ 会话会自己压缩上下文：聊很久的群不再撞模型上限**

- 🗜️ 群聊 / 好友 / 主人私聊的会话现在挂上了上下文压缩（窗口 15% 触发、留最近 5% 原文）：它们由桥直接 `resume/create`，绕过了 Web 的预设编排，而宿主级压缩在 Web 层是关着的，所以之前根本没挂压缩器——群 795789868 长到八十多万 token 后连着九轮 `CONTEXT_WINDOW_EXCEEDED`；
- 🩹 已经超限的旧会话不用重置：下一次请求撞到上限时，压缩器会把旧对话压成摘要再自动重试，聊天记录仍然留在磁盘上；
- ✅ 压缩预设注册失败只写进日志，不会影响聊天本身。

## 0.2.63

**群里先认清楚是谁在说话：别人的话不再算到另一个人头上**

- 🧑‍🤝‍🧑 同一个人按 QQ 号认，不只看名片：名片重名的两个群友不会再被并成一条消息，各占一行；
- 🖼️ 每条消息行尾标出 `[图 N]`，和下面【图 N·说话人】的图注同号：她不用猜这张图是谁发的；
- 🧠 记忆摘录不再写死“最后一个发送者”：一批里有好几个人的话时，这一段记忆不再标成某一个人说的，长期记忆不会把乙的话记到甲头上；
- 📝 群聊提示、短期记忆开头都写明「每行开头是谁的名字，就是谁说的」；短期记忆按行拆开，一人一行，不再把两个人的话挤成一句（鱼脑 0.6.2）；
- ✅ 补了名片重名、多人同批、图片编号、短期记忆一行的社交半边与鱼脑测试。

## 0.2.62

**群里不插两个人的话，也不硬接游戏：她只接冲自己来的，和真的聊得来的**

- 🙅 群消息在回复 / 引用另一个人，或者 @ 了别的群友时，默认不进判断、不接话，也不占待看队列；
  引用原消息查不到（太旧、后端没有 `get_msg`）也按“在跟别人说”处理，宁可少插一句；
- 🎮 她不玩任何游戏：群里聊游戏、开黑、排位、上分、抽卡、常见游戏名时在判断前直接略过，不花判断的钱；
  同批其他正常消息照常处理，不会因为一条游戏话题整批停摆；
- 🗣️ 被直接叫到时仍然回复：引用别人的同时点了她，只接和她有关的那半句；被叫到问游戏，也只照实说“我不玩 / 不太懂”，不装懂、不编经历；
- ⚙️ 设置页新增「不玩、不聊游戏」开关和「其他不聊的话题」；关掉游戏开关后游戏照常聊，自定义话题仍会在判断前挡下；
- 🏷️ 判断和回复提示给这类消息加 `[对别人说]`、`[不聊:…]` 标记，空 @ 的续叫不会错误地继承到别人的对话或游戏话题上；
- ✅ 补了 @ 别人、引用别人、游戏话题、直接叫她、关闭开关和自定义话题的社交半边测试。

## 0.2.61

**群里的引用不再只剩一句正文：回查被引用的话带进上下文，回复她也认得更稳**

- 💬 收到带 `reply` 段的消息时，向 QQ 后端 `get_msg` 回查被引用的原消息，把 `[引用谁：原话]` 放在正文前一起交给判断和回复；
  原话太长只带前 160 字，同一条引用缓存复用，不反复请求；
- 🪞 被引用的是她自己发的消息时标成 `[引用你：原话]`，并直接算作“在回复她”：重启后或超过 500 条 id 被清掉，也不会漏认；
- 🧯 回查失败（消息太旧、后端没有 `get_msg`、超时）不拦正文，只跳过引用原文；失败短时间不重试，日志 10 分钟最多一条；
- 🏠 主人桥（转群 / 转私聊）同样展开引用，但按发送人名字标，避免把主人自己的话写成她说的；
- ✅ 社交半边和宿主半边各补了引用原文、引用她、查不到原文的测试。

## 0.2.60

**短期记忆至少管一小时：回复不再只记得眼前一条，也把干净对话交给鱼脑**

- 🧠 群/好友会话的最近消息缓冲从固定 30 条改成按时间留一小时（最多 240 条，同一 id 去重）：聊天不密时也能接上几十分钟前的话，不再被条数一刀切；
- 📜 回复自带的上下文从最近 8 条放宽到最近 20 条、约 2400 字；提示总字数上限从 6000 提到 8000，被叫的消息一条都不丢，再按从新到旧补上下文，最后才丢更早的；
- 🧹 给鱼脑的来源里多带一份 `source.excerpt`：只留“谁：说了什么”，不带群公告、人物卡、好感度和【最近聊过】这些脚手架，短期记忆里看到的是真对话；
- ⏳ 场景提示写明“这间屋里最近一小时聊过的事都记得”，别把几分钟前说过的当成没听过；
- ✅ 补了 25 条长批、20 条上下文、过一小时自动清理和干净摘录的社交半边测试。

## 0.2.59
