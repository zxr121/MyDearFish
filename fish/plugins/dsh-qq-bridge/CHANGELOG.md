# 改动记录

> **版本号规矩**：每改一次 **+0.0.1**；末位满 10 **进位**（`0.1.9` → `0.2.0`）。
> 版本号只写一处真源：`package.json`；提交信息也以版本号开头。

## 0.2.39

**她会连着发几条气泡了**

- 💬 社交和主人私聊的场景提示都教了她连发约定：想连着发时，段与段之间空一行，每段作为一条消息单独发出，一次最多 3 条；
- 🔓 拆段不再只认空行：没有空行时，单独的换行也按分条算（聊天里几乎不会真的要一条多行气泡）；
- 🛡️ 连发超过 3 条时，多余的段落并进最后一条发出，不再被悄悄丢掉；
- 🧪 补了拆段纯函数和端到端连发（私聊 + 群）的用例。

## 0.2.38

**快判不再硬卡门槛，被叫权重更有保障**

- 🔓 快判从"分数不够就丢掉"改成"按分数排序取前 N 条"：低分消息只是排后面，不是直接丢掉；
- 🔓 `快判最多` 默认 3 → 8：一批里更多消息能进到判断模型，多人同时说话时她不会只盯着一两个；
- 🔓 被 @ / 叫名字 / 回复她（+3）权重至少和一条兴趣词（+2）相当，保证多人说话时她能先看到叫她的；
- 🔓 `判断阈值` 默认 0.55 → 0.4：中等兴趣也会开口；
- 🔓 `探索间隔秒` 默认 600 → 180：新话题更快被她看见。

## 0.2.36

**判断不用再等冷却**

- ⚙️ `判断冷却秒` 默认 20 → 0：每轮轮询（6 秒）只要有待看消息就判断，新消息不再额外等冷却；
  单次判断只是便宜的小模型调用，零花钱下限和快判仍然兜底。
- ⚙️ 设置页下限从 5 秒放宽到 0 秒；想省判断费仍可调大，冷却期间消息会攒着一起判。
- 🧪 补了「判断冷却 0 时下一轮轮询仍会判」的链路用例。

## 0.2.35

**关系跟着人走，群和私聊不再各算各的**

- 🤝 每个人只留一段总关系（熟悉度、暖度、张力、聊过几次、被叫几次），群和好友私聊共用；
  每间屋只再留一份相处统计和片段，换一间屋不重置关系。
- 🧠 人物卡和关系分寸改用总关系：在别处认识的人，换一间屋不会装陌生，也不会把别处的原话搬过来。
- 📚 事实和边界跟着人走并保留来源屋；私聊里知道的事标「私下」，她知道，但不会在群里点名复述；
  一个人的私事仍然不会说给另一个人。
- 👀 人物志点开后先看总关系，再看带来源的「记得 / 别碰」，最后才是各间屋的相处统计和片段；
  `GET /dsh-qq-bridge/people` 同步返回总关系。
- 🧪 把原来的“跨屋隔离”用例改成“跨屋互通 + 隐私例外”用例，并补了总关系累积的断言。

## 0.2.34

**想接时几秒就能开口**

- ⚙️ 接话冷却大幅缩短：默认基础 60 → 15 秒，来劲时最短 5 → 2 秒，最长倍率 1.5 → 1.2。
  同样“想接”的把握下，等待从约 25 秒降到 2–6 秒；只有勉强想接时才接近 15–18 秒。
- ⚙️ 判断冷却默认 60 → 20 秒，学习期 10 → 20 秒；热门群里她看新消息的间隔也一起缩短。
- ⚙️ 设置页同步放宽：冷却秒最低可设 2 秒，判断冷却秒最低可设 5 秒。
- 🧪 补了默认冷却曲线的用例。

## 0.2.32

**她会认人、记事、处关系了**

- 🧑‍🤝‍🧑 新增人物志：每个 QQ 号一份全局身份（名字 / 别名、初见、见过多少天），
  每个群 / 好友一份独立关系（熟悉度、暖度、张力、互动次数、相处片段）。
- 🧠 认识人会改变她怎么说话：判断和回复提示里带上人物卡（关系阶段、认识多久、这次隔了几天、口气、
  这间屋里记得的事和明确说过的边界），并按在场的人给关系分寸——生人客气、熟人放松、
  有过别扭就短一点、对方递台阶就顺着下。
- 📈 关系只随真实相处慢慢长：见过、隔天、被叫、她真开口、听到新事实都会加深熟悉；
  冲她发的负面话比好话更重，道歉能明显降温，时间会把张力磨掉。群里她只是看过、没开口，
  不算跟对方聊过。
- 🧾 长期事实和相处片段由判断模型顺带提取，不额外多调一次模型；只认她这次真看见的消息 id，
  只记短句，不记聊天记录。联系方式、住址、证件、账号、钱、健康、性和别人的隐私一律不落盘。
- 🔒 跨屋不串：在这间屋只说她在这间屋知道的事；私聊里知道的事标成「密」，绝不会带进群里；
  「别在群里提」这类边界也只在本屋生效。
- 🚀 快判把「在这间屋已经是熟人」也算作对话信号；设置页新增「记人」开关和人物志状态。
- 🧪 补了关系阶段 / 口气 / 累积 / 清洗 / 边界的纯函数用例，以及记事实、跨屋隔离、边界提示、
  “她真开口才记互动”的链路用例。
- 📝 人物志存在 `.dsh/qq-social-people.json`，只在本机；关掉「记人」后不再读写。

## 0.2.31

**问到她自己的关系，不再装没看见**

- ✨ 新增自关系问句识别：没 @、没提名字，只要在问她本人（你是谁、你哪来的）或她和主人 / 亲近的人的关系
  （“评价一下你的老爹”“你俩什么关系”），快判直接绕过兴趣门槛交给慢判，刷屏时也不会被挤掉。
- 🧠 慢判提示和社交提示区分“私事细节”和“关系本身”：主人的姓名、住址、账号、余额仍然不往外说，
  但被问到关系时至少应一句——可以短、可以打岔、可以不细说，不能只输出 `[不接话]`。
- 🛡️ 慢判没挑中或没给出接话意愿时，自关系问句仍会让她看见最近 3 条并开一轮，理由记进日志。
- 🧪 补了自关系问句的正反例、快判放行、`[问你]` 标记、漏挑也会开一轮的链路用例。

## 0.2.30

**快判不再只看词面**

- ✨ 快判改成多信号注意力分：显式兴趣、屋里真正挑中过的话题、同一个人连发、熟人、问句、图片 / 表情、情绪、
  以及“接着刚才的话题”都会加分；达到 `快判阈值`（默认 1.5）才进判断窗口，一批最多放 `快判最多` 条（默认 3），
  被叫和主人的消息永远放行、不占名额。
- 📉 学到的兴趣按“见过 / 挑中”折算权重：满屋都在说、她却很少看的词权重会被压低；真正反复挑中的话题更值钱。
- 🧭 新增探索额度：整批都没兴趣时，每 `探索间隔秒`（默认 600 秒）挑一条没见过的交给判断模型看一眼，
  零花钱低于 `探索最低余额`（默认 ¥3）就不探索；链接、广告词、复读和太短的消息不做探索候选。
- 🧹 图片 / 表情占位符不再被当成话题学进画像；画像新增“见过的话题、熟人、探索次数”，并继续落盘。
- 🧪 补了注意力分、IDF 权重、占位符、广告过滤的纯函数用例，以及快判上限、探索间隔 / 余额闸门的链路用例。

## 0.2.27

**看得懂 QQ 群里的合并转发**

  展开超时 6 秒。后端没有这个接口、超时或回包坏了，外层文字照常进上下文，原处留 `[转发消息，没展开出来]`。
- 🧪 补了消息段识别、折叠格式 / 截断 / 嵌套标记的纯函数用例，以及主人桥和社交桥各一条展开成功、

## 0.2.25

**群聊接话不再有次数上限，最短 5 秒，冷却走曲线**

- ⚙️ 去掉 `每小时上限` / `每天上限` / `每天总上限`：接话次数不再有小时、天或全局封顶，
  唯一的硬闸门是鱼脑零花钱（可用余额不低于 `最低余额`）。状态页仍显示本小时和今天的
  轮数，但只作观察，不拦话。
- ⚙️ `冷却最短倍率` 换成 `冷却最短秒`（默认 5）：有效最短间隔从原来的 30 秒降到 5 秒；
  兴致最低时的上限由 `冷却最长倍率`（默认 1.5）决定，基础仍是 `冷却秒`（默认 60）。
  学习期的判断冷却（20→60 秒）和接话冷却（5→60 秒）也改成同一条指数曲线，不再线性爬升。
- ⚙️ 余额吃紧不再直接乘一个固定倍率：`余额吃紧线`（默认 ¥5）到 `最低余额`（默认 ¥1）之间，
  冷却按指数曲线从 1 倍平滑拉到 `余额吃紧倍率`（默认 1.5）；低于最低余额仍然直接不接。
- 🧪 补了曲线端点与中点、把握度到冷却、余额倍率、学习门槛的纯函数用例；社交冒烟改成
  11 秒内可再接一轮（旧版每小时 1 条上限已移除），并覆盖余额吃紧时拉长冷却。

## 0.2.24

**名片乱码不再污染记忆，社交会话真正没有工具**

- 🐛 SnowLuma 返回的 `sender.card` 可能夹带控制字符和乱码（实测含 `\b`、`\u0007`、
  bidi 标记等）；原先名片优先，这些字节会直接写进提示、`source.sender` 和鱼脑经历。
  现在名片里只要出现控制字符就整张作废，回退到去掉控制字符的昵称，再回退 QQ 号；
  名字最长仍然 32 字。
- 🐛 社交会话只挂了执行闸门，工具 schema 仍然对模型可见（实测 15–16 个，含 B 站发送、
  `recall`、`open_episode`、`working_directory`），和 README“社交会话没有工具”不符。
  现在创建社交会话时用 `tools.restrict({ allow: [] })` 隐藏全部继承工具，guard 继续兜底。
- 🐛 鱼脑不再给社交会话注册 `recall` / `open_episode`，也不注入引用这两个工具的记忆协议；
  工作台脚注在社交会话里不再提示用 `open_episode` 核对原文。记忆提示照常注入。
- 🧪 补了名片乱码回退昵称 / 正常名片优先 / 昵称去控制字符 / 全不可用回退 QQ 号 /
  社交提示与来源使用干净昵称 / 社交会话隐藏继承工具的回归；鱼脑补了社交会话不注册工具、
  主人会话照常注册的用例。

## 0.2.23

**刚启动、没配判断模型时不再把群消息整批丢掉**

- 🐛 判断模型默认跟“当前主人会话”走；桌面刚启动、主人还没开会话时找不到人，判断器直接
  报“没有可用的判断模型”，这批消息被当成“都没看”扔掉。现在跟回复通道一样回落到
  DSH 的默认模型，不用先手动开一个会话或填 `判断模型`。
- 🐛 “没有可用的判断模型”改按临时失败处理：消息留在待看队列，判断冷却过后自动重判，
  不会因为一次没模型就永久丢消息。
- 🧪 补了两条回归：不填判断模型时回落到 DSH 默认模型并照常开轮；连默认模型都没有时
  消息留在待看，模型恢复后重判。

## 0.2.22

**分得清哪句在说自己，不再跟着吐槽自己**

- 🐛 回复提示原先只写“群友：大肥鱼……”，把称呼当成了第三个人；她可能顺着别人的话一起

  别人说“她”时先看前后文，拿不准就短问一句或不接。
- ✨ 明确要求被调侃时用“我”回应，可以顶回去、顺着梗演、认错，但不站在旁边看热闹、

- 🧪 补了四条回归：场景提示带称呼归属、回复批次标 `[说到你]`、她自己和判断器的旧话都标成自己、有人叫她名字时也能标出在说她。

## 0.2.21

**冷却跟着兴致走：来劲时说得勤，没兴致 / 快没钱时收着**

- ✨ 零花钱低于 `余额吃紧线`（默认 5 元）时，冷却再乘 `余额吃紧倍率`（默认 ×1.5）；
  到 `最低余额` 仍然直接收口。

- 🧪 补了三条回归：高把握 44 秒后能再开口、低把握 61 秒仍只看不回、余额吃紧时 44 秒只看不回。

## 0.2.19

**学会人的聊天节奏：该接就接，该短就短**

  上下文连续，但不混进主人平时那间屋子。
- ✨ 被 @ / 叫到名字 / 回复她的消息 → 直接回；没被叫 → 便宜的小模型判断要不要接，`[不接话]` 就不发。
- ✨ 成本闸门：静音、冷却、单目标小时/日上限、全局日上限、鱼脑零花钱下限；判断也有独立冷却，

- 🔒 社交会话没有工具、不注入余额；记忆只查这一间会话（精确会话 id，群号前缀相同也不会串）；
  群友内容按不可信资料处理；对外发送失败关闭。
- 🔒 主人的群消息仍走原来的目标会话，不在社交桥重复回；她自己的发言靠 `get_login_info` 过滤。
- ⚙️ 设置页新增社交卡片：群/好友清单、模式、被叫直接回、旁听、限额、静音、称呼/兴趣词、

## 0.1.4

**`QQ → DSH` 这半彻底搬进插件，不再赖 BOT**

- 插件每 4 秒轮询 NapCat 的 HTTP 历史接口（`get_friend_msg_history` / `get_group_msg_history`），
  发现她新发的私聊/群消息 → 直接 `followup` 进目标会话。
- 只认 `私聊QQ` 这个人发的；自己的回话（self 消息）不会自我繁殖成死循环。
- 靠 `message_id` + 时间戳去重，同一条不重复转；总开关关 / 没选会话时只推进时间、不处理旧消息。
- 结论：**这台桌面只要 NapCat + 这个插件，BOT 可以完全不要了。**

## 0.1.3

**QQ→DSH 这半的 BOT 半场也接上了**（改在 Estrella 那边，不在本仓库）

- Estrella（BOT）加了 `custom.qqBridge` 开关（**默认关**）：打开后，私聊/群里**她本人**说的话
  由 BOT 转发到本插件的 `/receive`，然后 BOT **闭嘴不回**，全交给 DSH 的大肥鱼。
- 兜底：转成功 → BOT 不回；转失败（DSH 没开 / 连不上）→ BOT **照常回**（桥断 ≠ 鱼哑）。
- 本仓库只是把这件事写进 README（见「怎么把 BOT 接上」）；运行入口仍是 0.1.2 的 `/receive`。
