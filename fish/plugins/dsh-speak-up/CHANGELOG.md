## 0.1.5

**有改动时，底下自己浮出「保存设置」条**

- 改了任意要保存的项（数字 / 触发文案 / 开关 / 角色）→ 设置页底部浮出
  `⚠ 有改动还没保存　[保存设置]`，不用再滚到页面最下面找那个按钮；保存完它自己收起来。
- 没改动时**压根不渲染**（不占地方、不挡视线）。用的是 `position: sticky`，只在这一页里浮着。

## 0.1.3

**英文名改成 `dsh-speak-up`**（原来是 `dsh-her-words`）

- 包名、插件 id、路由前缀、来源标记、配置文件名字全跟着改。
- ⚠ **旧配置会自动搬过来**：新配置文件不存在时，会退回读 `her-words-config.json`，设置不丢。
- 宿主半边文件名 `lib/index.js` → `lib/host.js`（跟 `lib/client.js` 配一对）。
- 顺手修：**改了「掷骰子间隔」保存后立刻重挂定时器** —— 原来是等旧的那一轮走完才生效
  （把 15 分钟改成 1 分钟，得先干等满 15 分钟才有第一次滴答，看着像坏了）。

## 0.1.2

**「概率」改叫「命中线」+ 没中加成 + 冷却单独一格**

- 「峰时概率 / 谷时概率」→ **「峰时命中线 / 谷时命中线」**：每轮掷一个 0~100 的数，
  **掷到命中线以下才开口**（掷在上面就不开）。
- 新增 **没中加成**（默认 10：每没掷中一次，下一次命中线 +10；**0 = 关掉**）
  和 **加成上限**（默认 40）。**掷中（含试运行掷中）就清零**，从头开始。
- **搭话冷却**单独一格（默认 20 分钟，**0 = 不冷却**），不再偷偷借用「近阈值分钟」那一格。
- 记录改成**先说最终答案**，例如：
  `掷中 ✓ 掷出 15.0（命中线 20.0 —— 掷到 20.0 以下就开口）｜20.0 = 峰时命中线 20% × 时机因子 1（距上次说话 74.6 分钟）`

## 0.1.1

**峰谷分时**：贵的时候少开口，便宜的时候多开口

- 时段**写死、不用填**：周一~周五 `9:00~12:00`、`14:00~18:00` 是**峰时**；
  其余全部（含午休 `12:00~14:00`、晚上到早上、**周末全天**）是**谷时**。
- 两格命中线：峰时默认 **20**、谷时默认 **60**；两格填一样 = 不分峰谷。

## 0.1.0

**首发**：本地掷骰子 → 掷中就走 DSH 自己的一轮（`agent.followup`）

- 纯本地 `Math.random`，**掷骰子一个 token 都不花**；只有掷中之后那一步才花模型。
- 设置页：总开关 / 试运行 / 掷骰子间隔 / 安静时段 / 时机因子 / 目标会话（勾选清单）/
  触发文案 / 角色，外加「演练一次（绝不真发）」「真发一次（跳过等待）」两个按钮。
- 触发消息是 `user` 角色 + 自家 `source.kind` 来源标记（不冒充使用者发的消息）。
