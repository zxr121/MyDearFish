# dsh-speak-up（主动搭话）· 沉默越久越可能开口

给 DSH 里某个会话装一颗「会自己起话头」的心：**没人在跟她说话的时候，她也会按一条随时间上升的概率曲线先开口；到最长间隔一定开口。**

```
定时器到点
  └─ 按「距上次主动开口 / 最长间隔」和曲线类型算这一轮真实概率
       （纯本地 Math.random，一个 token 都不花）
       ├─ 没掷中 → 只记账，等下一轮
       └─ 掷中 / 到点 → agent.followup(message)
                         → DSH 自己开一轮（人格、历史、工具、记忆都是她自己的）
                         → 等她真的说出 assistant 正文
                         → 才把「上次主动开口」清零并写进状态文件
```

一句话：**概率、曲线、检查都不花模型；只有真的发起那一轮才花 token。** 到点这一轮概率是 **100%**，不会出现「到点了却因为没掷中而不说话」。

## 装

### 一、在 DSH 里装（推荐）

打开 **设置 → 插件 → 安装**，把这一行填进去：

```
github:Yuuyuko-uu/dsh-speak-up
```

或者命令行（`--profile` 照你平时那个写；桌面端一般是 `desktop`、网页端是 `web`）：

```bash
dsh plugin --profile desktop add github:Yuuyuko-uu/dsh-speak-up
```

装完**重启一次 DSH**，然后去 **设置 → 主动搭话** 看一眼在不在。

### 二、手动装（没有 `dsh` 命令、或者装不动的时候）

1. 把这个文件夹放到 profile 能找到的地方：
   `%USERPROFILE%\.dsh\profiles\<profile>\node_modules\dsh-speak-up\`
2. 在 profile 的 `package.json` 里，把 `dsh-speak-up` 加进 `dsh.profile.bundles` 数组；
3. `cordis.patch.yml` 里那一行会把它插进 loader（`id: speak-up`）；
4. **重启 DSH**。

### 三、开发时（想改代码、改完就想看到）

上面那个 `node_modules\dsh-speak-up` 做成**指向你这个文件夹的目录联接**（junction / 符号链接），
或者 `pnpm add link:<这个文件夹的绝对路径>` —— 这样改的就是装的那一份。

> ⚠ 改完插件代码，**只重启 DSH 才一定生效**（关掉插件再打开、重装都不一定重新读代码）。

## 怎么用

设置页（**设置 → 主动搭话**）里从上到下：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 总开关 | 开 | 关掉就完全不动 |
| 试运行 | 关 | 开着时概率照算，但掷中只记账、不真发；**保底也不会真发，计时不会重置** |
| 检查间隔（分钟） | 30 | 多久看一眼概率曲线；**不是概率本身**。到最长间隔那一轮仍会单独补一次 |
| 最长间隔（分钟，保底） | 180 | 到点这一轮概率强制 100%，会发起一轮真实主动聊天；范围 10~1440 |
| 曲线类型 | 慢热 | 直线 / 慢热 / 快起 / S形；四种都从 0 升到 100%，只是快慢不同 |
| 曲线强度 | 4 | 慢热/快起用：越大越弯；直线/S 形不用 |
| 峰时倍率 | 0.5 | 峰时（贵）概率乘这个数；1 = 不降，0 = 只在保底开口 |
| 谷时倍率 | 1 | 谷时（便宜）概率乘这个数；1 = 不降 |
| 安静时段起/止（小时） | 1 / 8 | 含起不含止；跨午夜也行；**起 === 止 = 不启用**。安静时段顺延保底 |
| 她能主动开口的房间 | 全部勾上 | 默认全部勾上（含 QQ 群 / 好友）；取消勾选 = 这间不再主动；勾一下**立刻自动保存**。QQ 群还要在「通到 QQ → 主动开话题」里勾选，否则这里勾了也不会起话；好友私聊仍走旧房间提示 |
| 触发文案（平时） | 见下 | 平时按概率命中时用的动机句子 |
| 保底文案（到点） | 见下 | 到最长间隔、强制发起那一轮用的动机句子；没有鱼脑由头时用它 |
| 角色 | user | 见下面「做不到的地方」—— **developer 目前送不了**，本插件会拒发 |

### 概率怎么算（唯一真源）

令 `u = min(1, 距上次主动开口分钟 / 最长间隔分钟)`。曲线形状：

```
直线：u
慢热：(e^(k u) - 1) / (e^k - 1)     默认 k=4，前低后陡
快起：ln(1 + k u) / ln(1 + k)       默认 k=4，前快后缓
S形：3u² - 2u³                      两头缓、中间陡
```

这一轮真正会用的概率：

```
已过 >= 最长间隔（留 1 秒容差） → 1（到点保底，不分峰谷）
否则                            → clamp(曲线形状 × 峰/谷倍率, 0, 1)
```

- 曲线、日志、设置页的图都调同一个 `算概率()`，没有隐藏加成、没有「攒没中」「近远因子」「搭话冷却」。
- 峰时/谷时时段写死：**周一~周五 09:00–12:00、14:00–18:00 是峰时（贵），其余全是谷时**。要填的只有两个倍率。
- 到点那一轮不分峰谷，强制 100%，所以「最长间隔」是硬保证的**发起**，不是概率装饰。
- 安静时段不检查、不掷；结束后如果已超过最长间隔，立即补一次。因此**夜里最长沉默可能 = 最长间隔 + 安静时长**。

### 群里的开头内容（和这里分开）

- 本插件只决定「什么时候掷、掷中后挑哪间」；挑中 QQ 群后，具体带什么话头由 QQ 桥的 `qqSocial.开头建议` 决定（带进来 / 问大家 / 接旧话 / 自己的事 / 点名）。这里不再用「看一眼群里正在聊什么」。
- 允许哪些群、开头类型、最小安静、每屋每日、冷却、新鲜事，都在「设置 → 通到 QQ → 主动开话题（群）」；默认对所有能说话的群生效，可以逐群关掉。
- 桥不在 / 旧版桥没有开头建议时，回退旧的房间提示；桥说「这轮没有合适由头」时不 followup、不重置计时，只在记录里写原因。
- 演练一次会传 `{登记:false}`：只生成提示、不占下一轮的待发位；真发时才登记。
- 检查间隔只决定多久看一眼曲线；检查间隔 ≥ 最长间隔时，平时概率用不上，只会在到点检查。

### 计时口径

- 按「她上次**主动**开口」全局计时；正常回复主人、主人说话都**不重置**。
- 只有确认她真的说出 assistant 正文（或手动「真发一次」后确认成文）才重置。
- 手动「演练」、试运行掷中都不重置。
- 计时存在 `%DSH_HOME%/speak-up-state.json`，DSH 重启不会悄悄归零；缺失/坏掉/时钟回拨会按现在重新计时并记一条。
- 到点发起后如果没房间能开口 / QQ 桥挡住 / 模型没产出正文：**只记录，不直发罐头话**；下一轮仍在逾期，会继续按 100% 尝试。

### 峰谷省钱

时段是写死的，不用你填：

```
峰时（贵）：周一~周五  09:00–12:00 和 14:00–18:00
谷时（便宜）：其余全部 —— 含 12:00–14:00 午休、18:00~次日 09:00、周六周日全天
```

判断用**这台机器的本地时区**。两条曲线各自随时间上升；进入峰时会切换到较低那条，所以实际概率可能在 09:00 等边界跳变一次——这是省钱设计，不是概率造假。

触发文案 / 保底文案的默认值都是中性的（发布用）。**在设置页改成你自己的口吻就行**，不用动代码。这两段只用于**主人自己的会话**；QQ 群由 QQ 桥给具体话头，好友私聊仍走房间提示，不会把你写的话原样端给外人。

配置文件落在 `%DSH_HOME%/speak-up-config.json`（本插件自己一份，不碰 DSH 的 config）。
改名（`dsh-her-words` → `dsh-speak-up`）之前的 `her-words-config.json` 还会被兜底读一次，设置不丢。

## 怎么安全地试（**建议按这个顺序**）

1. 装好、重启，打开 **设置 → 主动搭话**，确认页面顶部有概率曲线图，记录里有那条启动日志：
   `已装好 v0.2.5：每 30 分钟检查一次｜最长间隔 180 分钟｜曲线 慢热 k=4｜峰时 ×0.5 / 谷时 ×1｜……`。
2. 「她能主动开口的房间」**默认全部勾上**（含 QQ 群 / QQ 好友）。不想让她在哪间开口就**取消勾选**（**点一下就生效，不用再按保存**）。
3. 想先不动真的，就 **打开「试运行」**（出厂默认关 = 到点会真发）。
4. 点 **「演练一次（绝不真发）」**：它不掷概率、不动保底计时，直接走一遍「本来要发什么」。**不会真发。**
5. 让它自己按检查间隔跑几轮，看每条记录里的 **本次概率** 和掷出值；图上纵轴就是这一轮真正会用的概率。
6. 时机满意了，**关掉「试运行」**。之后只有掷中（含到点保底）才会真发。
7. 想当场验证：点 **「真发一次（跳过等待）」**，然后去对应的会话 / QQ 群里看有没有多出一轮；她真的说出正文后，记录里会写「已确认」并重置保底计时。

随时可以再打开「试运行」让它安静下来。「总开关」关掉则连记录都不再走；打开后如果已经超过最长间隔，会立即尝试一次。

> ⚠ 改**数字 / 曲线 / 文案 / 开关**之后要点「保存设置」——页面顶上会显示「⚠ 上面有改动**还没保存**」。
> 只有「她能主动开口的房间」的勾选是**一点就自动保存**的。有改动时底下会浮出保存条，不用滚到最下面找。

## 做不到的地方（诚实清单）

### 1. 触发消息**只能**是 `user` 角色，`developer` 送不了

这是当前 DSH 版本的硬限制，不是本插件偷懒。三条证据：

1. `@deepseek-ai/dsh-agent-loop/lib/index.js` 的 `step()` 把收件箱认领到的消息**写死**成 `user/message` 事件，完全不看 `message.role`；
2. `@deepseek-ai/dsh-session/lib/index.js` 的 `append()` 校验「`user/message` 事件必须 user 角色」，`user/message` + developer 角色会直接抛错；
3. `developer` 消息在 `dsh-llm` 里会被 `withoutDeveloperMessages()` / `projectToolUpdates()` 从发给模型的请求里摘掉，就算塞进去模型也看不见。

**本插件的处理**：送出去的是一条 `source.kind = "speak-up"` 的 **user** 消息 —— 角色上确实是 user，但来源标记是她自己的，不是她打的字。设置里的「角色」填成 `developer` 时，插件会**主动拒发**并记一条，而不是去写坏会话日志。

### 2. 本地会话只认**活着的** agent；QQ 房间按需开

本地目标会话没有活着的 agent 时，什么都不做、只记一条（故意不偷偷唤醒冷会话）。
QQ 群 / QQ 好友靠 QQ 桥暴露的 `qqSocial` 服务先确认这间**现在能不能开口**（总开关 / 社交开关、单独开关、只听、歇着、试运行、静音、主动话量）；群还要过 `能开头`（是否勾选、今天次数、冷却、屋里是否安静/热聊），没勾选或现在不适合起话就不选它。能开口就顺手让桥把会话开出来；桥没装、开不出来或任何一条不满足时，只记账、这轮不开口。

### 3. 保底是「发起真实回合」，不是「QQ 一定送达」

确认口径是「DSH 会话里有没有她的 assistant 正文」，不是 QQ 送达回执。QQ 桥的额度/静音/只听等主人开关仍然优先；桥挡住时只记录，不直发绕过。到点如果没房间或模型没产出正文，也只记录，**不会在插件里塞一段死文字冒充她说话**。

### 4. 设置读写走本插件自己的 JSON，不是 DSH 原生「插件配置」页

插件装在 profile 的 `node_modules`，那里没有 `@deepseek-ai/schemastery`，静态 import 会让整个插件加载不了。所以本版跟 `dsh-write` 等设置插件一样：自己的 json + 自己的设置页。

### 5. 别的地方也**没验证过**

- 设置页的 SVG 图在真实浏览器里的最终像素（浅色/深色）以实际渲染为准；冒烟只验结构、坐标轴、曲线和交互请求。
- `settings.section` 槽位名：跟 `dsh-write` 等其他设置插件用的是同一个，在这台机器上跑通；换 DSH 版本可能变。
- QQ 房间的 `qqSocial.开房` 这条路在假 ctx 里验过；真机上桥没装/没连时只记账。
- **待确认不持久化**：DSH 在等正文期间重启，会清空待确认、保留旧计时，下一轮可能重试一次。

## 它到底做了什么（给下一个看代码的人）

- `lib/host.js`（宿主半边）：配置读写 + 状态文件 + 曲线纯函数（`形状值` / `算概率` / `检查时刻分钟` / `安静结束时刻` / `算曲线` / `下次检查毫秒`）+ `ctx.timeout` 递归排程 + 掷概率 + `agent.followup(message)` + assistant 正文/`turn/end` 确认 + 五条 `/dsh-speak-up/*` 路由 + 内存里最近 60 条记录。
- `lib/client.js`（网页半边）：`settings.section` 槽位里的「主动搭话」设置页；内联 SVG 直角坐标系图（两条曲线/检查点/当前点/保底线），曲线参数改动会 debounce 调 `/curve` 预览；房间勾选立刻自动保存；数字/文案类改完要点「保存设置」。
- 两边**只有一份概率逻辑**（在宿主那边），网页只负责读写和画宿主返回的曲线数据。
- `CHANGELOG.md`（[改动记录](CHANGELOG.md)）：每一次改动一行一条。**版本号规矩：每改一次 +0.0.1，末位满 10 进位。**
